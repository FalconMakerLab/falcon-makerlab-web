## About the project

The Raised Bed Connector is a planned project story from MAKE and GROW: designing a physical component for use in the garden.

The illustration is conceptual. It is not a manufacturing drawing or a statement of verified specifications.

## From a need to a prototype

Documentation will cover the connection problem, dimensions, model and assembly method.

## What the documentation will include

- Model and printable files.
- Material selection and print settings.
- Assembly photographs and garden testing.
- Lessons from use and changes for the next version.

## Status

Documentation in progress. Files and recommendations will be added after the design has been verified.
