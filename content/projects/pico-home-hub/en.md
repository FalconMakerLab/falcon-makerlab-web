## About the project

Pico Home Hub is a home automation project based on Raspberry Pi Pico. It brings together CODE and MAKE: software and electronics.

This page is a starting point for future documentation. The illustration is a visual concept, not a photograph of the actual device. Specifications, photographs, test results and the correct repository link will be added after the project materials have been verified.
